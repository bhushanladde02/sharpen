Method: every successfully served HTML page is counted once, server-side, in the application's own PostgreSQL database (table page_view). Requests whose user agent identifies a crawler, monitor or command-line tool are excluded. A visitor is a salted hash of (day, network address, user agent), so one browser counts once per day and cannot be identified or followed across days; no cookies or third-party scripts are used. Sign-ups, sessions and reports come from the application's account, session and report tables. Source code: https://github.com/bhushanladde02/sharpen (AGPL-3.0). © Bhushan Arun Ladde.
