Browser extension

The Sharpen extension (in chrome-extension/ of the repo) times your visits to ChatGPT, Claude, Gemini, Copilot and Perplexity, counts prompts, and posts them here once a day with your API key. Nothing you type is captured — only time, prompt count and site.

Set it up: copy your API key, open the extension popup, paste the key and the portal URL.

Provider usage export

Upload the CSV from your OpenAI or Anthropic usage dashboard as-is. Rows become one session per day per model with request and token counts; minutes are estimated at three per request until you rate them.
